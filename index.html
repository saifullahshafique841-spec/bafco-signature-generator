Outlook desktop (classic)

Click Copy signature. In Outlook go to File > Options > Mail > Signatures, click New, name it, click inside the editor box and press Ctrl+V. Click OK.

New Outlook / Outlook on the web (OWA)

Click Copy signature. Open Settings (gear) > Accounts > Signatures, create a new signature, paste with Ctrl+V and Save. Choose it as the default for new messages and replies.

Tip

If pasting loses formatting, use Download PNG and insert the image into the signature instead (Insert picture).
